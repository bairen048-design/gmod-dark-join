# GMod 挤服护眼补丁

Windows 版 Garry's Mod 本地深色界面补丁。反复按 Enter 连接满员服务器时，减少加载页、服务器列表和连接失败弹窗之间的亮度变化。

## 下载与安装

[直接下载最新中文安装包](https://github.com/bairen048-design/gmod-dark-join/releases/latest/download/gmod-dark-join-v2.2-windows.zip)，或前往 [Releases](https://github.com/bairen048-design/gmod-dark-join/releases/latest)。

1. 关闭 Garry's Mod。
2. 完整解压安装包，不要在压缩包内直接运行。
3. 双击 **安装护眼补丁.bat**。
4. 自动找到游戏后完成安装；找不到时，复制 Steam → Garry's Mod → 管理 → 浏览本地文件中的文件夹路径，粘贴到安装窗口。
5. 重新启动游戏。

已安装旧版的用户可以直接安装新版。恢复时关闭游戏，运行 **恢复原版.bat**。

## V2.2 包含什么

- 固定深灰色加载页，保留连接状态和下载文件名。
- 深色服务器列表、选中行、鼠标悬停、玩家面板和搜索框。
- 补齐屏幕右侧、底部的背景，并调暗底部导航按钮。
- 将原生连接失败弹窗底板设为 `#1e1e1e`、按钮设为 `#282828`，使用柔和浅灰文字。
- 自动查找 Steam 游戏库、备份原文件，并提供恢复入口。

## 工作方式与范围

这是本地界面补丁，**不是 Steam 创意工坊订阅插件**，不要放进 `addons`。安装器修改游戏目录内的以下文件：

| 文件 | 修改内容 |
| --- | --- |
| `garrysmod/html/loading.html` | 替换默认加载页面 |
| `garrysmod/html/css/menu/Servers.css` | 添加有标记的深色样式 |
| `garrysmod/resource/SourceScheme.res` | 替换指定的原生控件配色键，保留字体和布局 |
| `garrysmod/cfg/autoexec.cfg` | 添加有标记的 `cl_enable_loadingurl 0`，关闭服务器自定义加载网页 |

备份位于游戏目录的 `garrysmod/dark_loading_backup_v1`，请保留此文件夹，以便自动恢复。

原生窗口与按钮共用主题，因此其他原生窗口也会变暗；底部导航栏在其他菜单页面也为深色。补丁不会修改服务器连接逻辑或自动重连。

安装器离线运行，无额外运行时依赖，不上传个人信息；源码可直接查看。Windows 通常自带所需的 PowerShell。启动脚本只对本次 PowerShell 进程设置执行策略。

## 验证与已知限制

- 安装、重复安装、旧版升级、恢复，以及保留用户新增配置的流程经过模拟游戏目录测试。
- 全屏背景与导航覆盖在 1920×1200、1280×800 的浏览器预览中检查过。
- 原生主题配色键与恢复流程使用实际游戏主题文件的副本检查过；原生弹窗的最终效果仍需在游戏中验证。
- 不保证消除引擎层面的单帧闪白。
- 游戏更新或验证完整性可能还原修改。文件发生冲突时，安装器会提示；请保留现有文件与备份。
- 如遇访问被拒绝，先查看脚本，再按需要以管理员身份运行安装或恢复入口。
